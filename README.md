# Chapel Connect

Build a modern, premium, responsive website for the Elizade University Chapel.

The website is for the Christian Chapel community of Elizade University, Ilara-Mokin, Ondo State, Nigeria.

I have uploaded the official Elizade University Chapel logo. USE THIS EXACT LOGO throughout the website. Do not recreate, redesign, distort, or replace the logo.

BRAND IDENTITY

----------------

The uploaded logo should be the main source of the website's visual identity.

Use the deep navy/dark blue from the logo as the PRIMARY and MOST IMPORTANT brand color.

The color palette should be based on the logo:

- Primary: deep navy blue from the logo

- Secondary: slightly lighter shades of the same blue

- White: main background color

- Very light blue: subtle section backgrounds

- Gold: use sparingly as an accent because the logo contains gold

- Dark text: for readable body text

The website should feel:

- Christian

- Elegant

- Modern

- Youthful

- Welcoming

- Professional

- Peaceful

- Spiritually inspiring

Do NOT make the website look old-fashioned or overly religious in design.

It should look like a modern university Christian community website.

IMPORTANT:

The blue from the logo must dominate the design.

Use generous white space, clean typography, subtle shadows, rounded cards, smooth animations and modern layouts.

WEBSITE STRUCTURE

-----------------

Create the following pages:

1. HOME

2. ABOUT

3. GALLERY

4. GIVING

Navigation:

Logo | Home | About | Gallery | Giving

Add a mobile hamburger menu for smaller screens.

The navigation should be sticky/fixed at the top when scrolling.

Use smooth scrolling and subtle page transitions.

--------------------------------------------------

https://eu-drama.vercel.app/

Study the overall feeling and structure of the introduction on that website, but DO NOT copy its content, branding, text, images, or exact design.

Create an original Chapel version.

The hero should include:

- Elizade University Chapel logo

- Large welcoming headline

- Short spiritual statement

- Primary CTA button

- Secondary CTA button

- Beautiful Christian/university-themed background imagery

- Subtle animations

- Smooth entrance animation

Suggested supporting text:

"A community of students growing in faith, fellowship, and the knowledge of Christ."

Primary button:

"About Our Chapel"

Secondary button:

"Explore Gallery"

Make the hero visually powerful but not cluttered.

Add subtle animated elements such as:

- Fade-in text

- Slide-up animations

- Gentle image movement

- Floating decorative elements

- Smooth scrolling indicator

Do not overuse animations.
